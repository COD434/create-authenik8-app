---
name: Design CSS
description: Generate CSS custom properties from an Authenik8 tokens.json design bundle
---

Render `tokens.json` as CSS custom properties on `:root` using
`@authenik8/design`. One source of truth: the tokens file, never the CSS.

## When to use

- Applying a design system to an app: generate the CSS variables the
  styles consume.
- After any `tokens.json` edit: regenerate instead of hand-editing.

## Workflow

1. Render to stdout to inspect (no writes):

   ```
   node <skill-dir>/scripts/css.mjs <design-dir>
   ```

2. Write the file the app imports:

   ```
   node <skill-dir>/scripts/css.mjs <design-dir> --out src/styles/tokens.css
   ```

   The output starts with `/* Generated from tokens.json — do not edit by
   hand. */`. If the target file exists and LACKS that header, it was not
   generated by this tool — confirm with the user before overwriting it.
3. Never hand-edit the generated file; change `tokens.json`, re-run, and
   finish with the design-audit skill (exit 0) before committing.
4. Custom selector when the app needs one: `--selector ".theme-dark"`.
