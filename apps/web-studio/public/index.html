    Publish the current Studio project to an existing GitHub repository in one commit. Click Publish again when you want to sync later changes.
    
          
          
    The token is used for each request only and is never saved. For CI, grant repository metadata read and Actions read. Inspect the filenames and file contents before publishing; anything included is sent to GitHub.
