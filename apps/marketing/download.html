Download Studio for Windows.

Install Studio once, then build and run projects locally. Your files stay on this machine. Studio opens in your browser and does not need a hosted workspace.

Windows 10 or newer - 64-bit

The installer includes the runtime. You do not need to install Node.js separately.

Get Windows installer

Studio runs on localhost. Add your model key in the app when you are ready to build. Download the installer and SHA-256 checksum from the latest GitHub release. Release notes state whether the installer is Authenticode-signed.

Developers can also run npx create-authenik8-studio with Node.js 22 or newer. See the quickstart for source development.
